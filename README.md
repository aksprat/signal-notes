# Signal Notes

A static, content-driven personal AI blog and portfolio built with Astro.

## Run locally

```bash
npm install
npm run dev
```

## Update the site

Most ongoing edits happen in [src/data.ts](src/data.ts):

- Update `profile` with your name, email, and real YouTube channel URL.
- Replace the sample `articles`, `videos`, and `builds` with your published work.
- Use `url` for an article or video that is already hosted somewhere else. Leave it out to use a page generated by this site.

## Build

```bash
ASTRO_TELEMETRY_DISABLED=1 npm run build
```

This writes the deployable static site to `dist/`.

## DigitalOcean App Platform

When you are ready to deploy from a Git repository, configure a **Static Site** component with:

- Build command: `ASTRO_TELEMETRY_DISABLED=1 npm run build`
- Output directory: `dist`
- Node version: `20.19` or newer

Set the final domain in `astro.config.mjs` before launch so generated URLs and metadata use your real website address.
